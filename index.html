From Arbitrary Audio to EDM

Spectral Retrieval of Discrete Rhythm Archetypes with Timbral Preservation

Lindsey Pietrewicz · DAFx 2026

GitHub → Paper →
A VQ-VAE trained on 7,999 EDM drum loops learns a codebook of 256 discrete rhythm archetypes. Spectral features from arbitrary input audio select the nearest archetype via nearest-neighbor retrieval. A velocity decoder predicts per-hit dynamics. The input's own sounds are placed at hit positions — producing EDM drums in the input's timbre.
The intended workflow: a musician provides any audio — field recordings, voice, instruments, found sounds — and the system outputs an EDM drum pattern built from those sounds. The examples marked Producer remix below show what happens next: a producer took the model output and used it as raw material to build a full track, demonstrating how this tool fits into a real music production workflow.
